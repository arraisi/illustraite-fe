# Task Completion Checklist

After completing a task:

1. **Build check:** `npm run build` — ensure no build errors
2. **No test suite** configured — manual testing via `npm run dev`
3. **No linter/formatter** configured — follow existing code style manually
4. Ensure PrimeVue components use Unstyled/PT mode only
5. Ensure `<script setup>` syntax is used in all Vue components
